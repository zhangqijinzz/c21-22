# LatencyLab

本地前端请求链路预算实验室。这里的推演是可重复的时间估算，不会调用真实接口。

## 本地运行

- 运行时：Node.js `>=20 <21`
- 安装依赖：`npm ci`
- 开发预览：`npm run dev`
- 质量门：`npm run lint`、`npm run test`、`npm run typecheck`、`npm run build`

## 功能模块

1. 链路项目：新建、改名、切换与复制项目。
2. 请求编排：增删节点、设置依赖及耗时、超时、重试、失败和降级参数；依赖变成环时拒绝连线。
3. 时序推演：乐观、预期、保守三种波动假设；不限并发或设置并发上限；展示完成预算、排队等待和关键链路。
4. 方案对比：保存当前图和计算结果，比较两份参数快照并恢复任一快照；正在编辑的链路无需存快照即可作为对比方，逐项查看参数差异与完成预算差距，勾选后整体应用或退回方案取值。
5. 本地项目区：管理、复制和删除项目，查看保存状态。

## 方案差异应用的取舍规则

逐项差异（节点字段、节点增删、并发上限）以勾选集合作为**一组整体改动**提交，提交前先跑规划器预检：

- 字段指向的节点已被删除：可恢复该节点后应用，或跳过该项；
- 方案中的依赖/降级目标在当前图不存在：可连带恢复目标节点、清除/忽略该引用，或保留当前取值；
- 差异生成后同一参数又被修改：选择采用方案值或保留当前值；
- 方案依赖会让当前图成环：跳过该项或终止整组应用。

只要存在未决取舍、选择终止，或应用后图无法通过校验/推演，整组改动都不会部分生效。提交成功后推演结果、快照列表与保存状态由同一次状态提交同步刷新，并生成一条可撤销记录（撤销按逆向规则精确还原；期间若手动改过图，撤销记录作废）。规则实现见 `shared/domain/liveDiff.ts`。

## 架构

`views` 只渲染状态并转发事件。功能 VM 将项目、节点、推演和方案用例分开编排；纯规则位于 `shared/domain`；Repository 依赖 IndexedDB Service，并写入版本化 localStorage 恢复副本。项目数据不会发到服务器。

默认示例：会话校验和功能开关并发启动；资料与目录在会话后开始；个性推荐等待功能开关和资料。结果使用确定性预算：延迟波动取所选情境、超时截断单次耗时、失败概率决定重试次数期望，重试退避按 200ms 指数增长并封顶 2 秒。降级耗时按最终失败概率加权。并发上限使用稳定拓扑顺序做资源排队估算。
